# Animal Cards 🐾🃏

A simple terminal-based card battle game built with Python 3. Players and an AI opponent use decks of animal cards with different power levels and battle each other until one deck runs out.

Each animal has a fixed power ranking, and the stronger card wins each round.

## Features

- 🃏 8 unique animal cards with power levels
- 🤖 AI opponent with automatic card selection
- ⚔️ Turn-based battle system
- 📊 Power comparison logic
- 🎮 Interactive terminal gameplay
- 🔁 Randomized shuffled decks each game

## Requirements

- Python 3.x

## Installation

```bash
git clone https://github.com/your-username/Animal-Cards.git
cd Animal-Cards
```

## Usage
```bash
python3 PY3animalcards.py
```

## How to Play

1. The game starts with both player and AI receiving the same set of animal cards
2. Both decks are shuffled randomly
3. Each round:
    * Opponent plays a card automatically
    * You choose a card from your deck
    * Cards fight based on power level
4. Stronger card wins the round
5. Game ends when a deck is empty

## Animal Power Ranking

* 🐭 Mouse (weakest)
* 🐔 Chicken
* 🐐 Goat
* 🐺 Wolf
* 🐃 Buffalo
* 🐅 Tiger
* 🦁 Lion
* 🐘 Elephant (strongest)

## Example Gameplay

Player chooses Lion 🦁
Opponent plays Wolf 🐺
👉 Lion wins the round
